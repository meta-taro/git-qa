# 改善要望シート雛形

**使った人が書く**表です。検証シート（`docs/test-specs/`）とは逆で、
行を起こすのは人間で、AI ではありません。規約の正本は
`.claude/rules/product-baseline.md` **§27**。

| ファイル | 用途 |
|---|---|
| `improvement-request-ja.tsv` | 雛形 |

実体は **`docs/feedback/improvement-request.tsv` に 1 枚だけ**置いてあります。
新しく起こす必要はありません。**使って気づいたことを、その場で 1 行足してください。**

## 書き方

- 文章は下手でよい。空欄のままでよい列があります
- 埋まっていてほしいのは「**何をしていたか**」「**どうなったか**」の 2 つだけ
- 原因や直し方は書かなくてよい
- **良かった点も書く。**不満だけ集めると、要望が付いていない機能と
  黙って使われている機能の区別が付かなくなります
- 行は消さずに積む（対応済も残す）

## AI がやってよいこと

**`状態` と `関連Issue` の 2 列だけ。**

要望を要約して短く書き直したり、AI 自身が思いついた改善案をここへ書いたりしません。
**要約した時点で、書いた人が本当に困っていた所が落ちます。**
