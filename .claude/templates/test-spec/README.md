|---|---|

## 配布のされ方

`/push-project` が本ディレクトリを配布リポの `.claude/templates/test-spec/` へコピーする
（`rules/product-baseline.md` → `.claude/rules/` と同じ扱い）。配布リポ側では
`docs/test-specs/<NNN>-<slug>.tsv` としてコピーして使う。

## 触るときの注意

- 1 行目 `#! md-business:test-spec-tsv/v1` は**行頭 0 桁**でないとグリッドで開かない。
  グリッド判定は**内容ベースで、拡張子は見ていない**（`.md` でもマジック行があればグリッドになる）。
  ただし配置規約として `.tsv` に統一する（§22）。
- セル区切りは**実タブ**。エディタの設定でスペースに変換されると壊れる。
- **区切りタブが 1 個足りないと、内容が左隣の列に黙って入る。**短い行（末尾の空セル省略）は仕様上許容されるため、
  ずれ先が text 列なら `validateTsv` は issues 0 で素通りする。**テキストエディタで手打ちしない**
  （グリッド編集か MCP の `update_tsv_row` で書く）。
- セル内改行は `\n`（バックスラッシュ + n）で書く。実改行を入れると 1 レコード = 1 物理行が崩れ、行がずれる。
- `#@ style`（条件付き書式）は**実装済み**。色は hex のみ、指定列の値が一致した行の**背景全体**に敷かれる。
- 変更したら md-business の実装で必ず通す（`packages/schema-test-spec-tsv/dist` の `parseTsv` / `validateTsv`）。
  2026-07-24 実測: rows=2 / validation 違反なし / round-trip 一致 / セル内改行の復元 OK。

## 変更手順

テンプレート・配置規約・命名規約は**全リポ共通**。変更は企画側リポで決定し、各リポへ Issue で通達する（§22 関連）。
