# 検証シート雛形

実物を動かして目で見ないと判断できない項目を置く表です。
規約の正本は `.claude/rules/product-baseline.md` **§19**。

| ファイル | 用途 |
|---|---|
| `standard-oss-ja.tsv` | 公開リポ用・8 列。**記入者・実施日の列を持たない** |

## 使い方

1. この雛形をコピーして `docs/test-specs/<NNN>-<slug>.tsv` として置く
2. ヘッダ（タイトル / 文書番号 / 対象 / 版）を埋める
3. 行を起こすのは AI でよい。**`結果` 列を埋めてよいのは、実物を動かして目で見た人だけ**

## このリポジトリでの扱い

- **リリースの関門にしません。**未実施の行が残ったままリリースしてよい
- **AI から実施を促しません。**催促の材料に使わない
- **自動テストで合否が出る項目はここに載せず CI へ置きます。**
  行が減るのは劣化ではなく、設計が進んだ証拠です
- **外部からの貢献者に記入を求めません。**PR の受け入れ条件は CI のみ

## 変えないこと

**AI が `結果` 列を埋めない。**ビルド通過もテスト green も「実施」ではありません。
空欄のまま置きます。
