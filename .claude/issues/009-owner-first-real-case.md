# 009 — [owner-task] 最初に使う実案件と 20 ケースを決める

- Phase: 0
- 前提: なし
- **担当: 人間（このリポの AI は着手しない）**

## 目的

**この道具が楽にする対象を、実物で 1 つ決める。**

Issue 008 の主指標は「同じ 20 ケースを、手で通した時間と比べる」。**比べる対象が実在しないと測れない。**

## 決めてほしいこと

1. **どの案件のどの検証を対象にするか**
   - すでに検証シート（TSV）が動いていて、人が記入しているものが望ましい
2. **20 ケース前後を選ぶ**
   - 全部通るケースばかり選ばない。**落ちるもの・判断に迷うものを混ぜる**（人が見る必要のあるケースが無いと、この製品の価値が測れない）
3. **対象は Android か、それ以外か**
   - Phase 1 は Android で作る。対象が Web しかない場合は、Phase の順序を組み替える必要が出る

## 完了条件

- 案件名とケースの一覧がこの Issue に書かれている
- **手で通したときの所要時間**が 1 回分ある（Issue 008 の比較対象。**この道具を作る前に測っておく**）
- 選んだケースに、**落ちるもの・判断に迷うものが含まれている**

## なぜ人が決めるのか

どの検証が面倒なのかは、実際にやっている人にしか分からない。**AI が「よくありそうなケース」を作ると、楽になったかどうかが測れなくなる。**

また、手作業の所要時間は**作る前にしか測れない。**道具ができてから測ると、道具を知っている人が手作業をやることになり、数字が歪む。

- 選んだ案件のデータには実顧客の情報が含まれる。**OSS のサンプルには使わない**（C10）
