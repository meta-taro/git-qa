# 012 — カラムの区切りを、マウスで動かせるようにする

- Phase: 1
- 前提: 003（3 カラムの骨格）
- 起票: 2026-09-02。**実物を触った人からの指摘**

## 何を言われたか

> 区切り線は、左右にマウスで移動できて、W クリックで所定の初期位置に戻るのも必要です。

## なぜ要るか

**中央（ライブビュー）が主媒体**（C4）だが、**どれだけ広く見たいかは、見る人と端末による。**
縦長の端末を見るときと、ケース一覧を見比べるときで、要る幅が違う。
いまは `columns.ts` の `flex`（1 : 3 : 1）で固定されている。

## 決めたこと

- 区切りは**カラムの間に置く**（2 本）。ドラッグで左右のカラムの取り分を移す
- **合計は変えない。**片方が増えたら、隣が同じだけ減る
- **ダブルクリックで既定（`columns.ts` の `flex`）に戻す**
- 幅の数値は CSS に書かない（C28 のまま）。`--column-flex` を書き換える
- **最小の取り分を決める。**0 まで詰められると、カラムが消えて戻せなくなる

## 完了条件

- 区切りをドラッグすると、左右のカラムの幅が変わる
- ダブルクリックで初期位置に戻る
- どのカラムも、最小の取り分より小さくならない
- 幅の計算がテストで固定されている（DOM に依存しない純粋な部分として）

## 注意

- **見た目（太さ・色）は決めない**（`DESIGN.md` が空・§11）。掴めることが分かる最低限にとどめる
- キーボードでの操作は今回入れない。**打鍵は判定に使っている**ので、割り当てを増やす前に
  実機で一本道を通してから考える
