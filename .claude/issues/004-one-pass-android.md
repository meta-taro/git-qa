# 004 — ★Android で一本道を通す（最初の山）

- Phase: 1
- 前提: 002 / 003 / 006
- 優先度: **最高**

## 目的

**この製品が解こうとしている問題が実物で見える状態を作る。**

> **TSV を読み込み、Android 実機を AI が操作し、人が横でライブで見て、1 打鍵で `VERIFIED` を置き、`run.json` が出るまで。**

## 通す流れ

```
TSV を読む（書き戻さない）
 → Android 実機に接続
 → scrcpy のライブビューが画面中央に出る
 → AI がケースを実行する（人は横で見ている）
 → AI が「判断保留」と言う / 落ちる / 差分が出る
 → 人が 1 打鍵で VERIFIED を置く
 → 次のケースへ自動で進む
 → runs/<ts>/<caseId>/ に証跡が出る
```

## 決めること（このリポで決めてよい・企画側へ選択肢を投げ返さない）

- AI が「判断保留」を出す条件
- 人が押すキーの割り当て
- ケース間の遷移（自動で進むか、1 拍置くか）

## 完了条件

- **5 ケース以上**をこの流れで通せる
- `run.json` に `VERIFIED` と `AUTO_PASS` が**混在している**（全部人が見る運用になっていないこと）
- **`VERIFIED` を置くのが 1 打鍵**で、押したら次のケースへ進む（C6）
- **合否は人が置く。AI が `VERIFIED` を宣言しない**
- TSV が**書き換わっていない**（C3。実行前後で `git diff` に出ないこと）

## 確認コマンド

```bash
git diff --name-only   # TSV が出ないこと
```
