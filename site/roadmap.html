ロードマップ

段ごとに「次へ進んでよい条件」を置いて進めています。作る順と測る順を分け、作る順は Android から、測る順は唯一の未知だった iPhone から。 git-qa が役に立つかどうかは、同じ 20 ケースを手で通した時間より、この道具で通した時間が明確に短いかで決めます。短くなければ、先へ進まずに画面を作り直します。

済み

1. Android で一本道を通す

  • 検証シート（TSV）を読む。書き戻さない
  • Android 実機・エミュレータに繋ぎ、ライブビューを画面の中央に出す
  • AI がケースを流し、人の番で止まり、1 打鍵で VERIFIED を置いて次へ進む
  • run.json に VERIFIED と AUTO_PASS が混ざった形で残る

次へ進んでよい条件：5 ケース以上をこの流れで通し、ライブビューの遅延が許せる範囲に入っている → 達成

済み

2. 証跡を残し、相手を広げる

  • 1 件ごとの画面と動画を runs/<日時>/case-NNN/ へ。録画は開始時の設定で、録らなかったことも証跡に残る
  • ウェブ（Chrome 系・Firefox・Safari。CDP を直に叩く）とデスクトップアプリ（macOS・Windows）の Adapter
  • iPhone / iPad を USB で映す・文字を読む・録る。押す・打つは端末に WebDriverAgent を入れたとき
  • 鑑賞モード（押さなくても進む）と、画面なしの無人実行（--no-ui）
  • 途中で止めて、次の日に続きから。シートが書き換わっていれば続けない
  • 試験 1 本を 1 つのフォルダにまとめ、証跡をフォルダごと git で管理できる
  • 配布物：macOS（署名・公証。Apple シリコン・Intel の 1 本）、Windows（x64・ARM64）

答え合わせ：ウェブとデスクトップの Adapter を足すのに、核の変更が要らなかったこと → 要らなかった

いま

3. AI エージェントと一緒に進める

  • MCP：画面を撮る・文字を読む・押せる名前を並べる・押す・なぞる・打つ・アプリを起こす。判定を置く道具は作らない
  • 公式の MCP 一覧（registry.modelcontextprotocol.io）に載せる
  • 外の道具から、シートとケースを指して起動する（git-qa://run?…）
  • シートに書けない値（ライセンスキーなど）を、手順に名前だけ書いて環境変数から打つ。足跡には名前のまま残る
  • アプリの起動画面から録画を選び、判定を置き終わった欄から証跡の場所を開く
  • iPhone / iPad で押す・打つを、実機で通す（WebDriverAgent の署名と導入は人の作業）
  • Windows のデスクトップで、まだ読めない入力欄を減らす
  • テスト中に見つけた別の問題を、ケースの合否とは別に記録する（Finding）
  • 人が途中で操作を引き取り、AI へ返す（Human Takeover）
次

4. 楽になったことを数字で示す

  • 同じ 20 ケースを、手で通した所要時間と、この道具で通した所要時間を測る（まだ 1 度も測っていません）
  • 1 ケースあたりの打鍵数とマウス操作の回数を数える

止めどころ：手作業より明確に短くなければ、先へ進まずに画面を作り直します。他が全部できていても、この数字が出なければ製品ではありません。

その後

5. 広げる

  • 前回の証跡との差分（変わった所だけを人に見せる）
  • Windows のインストーラーの署名（証明書に物理トークンか HSM が要る）
  • 新しい版の知らせ（いまは自動更新が無く、このサイトから落とし直す）

作らないもの

役に立ちそうでも、git-qa は次のものを作りません。

  • AI が合格を出す口MCP にも判定を置く道具は作らない。合否は人だけ。
  • 不正防止機構中身を見ずに VERIFIED を置くこともできる。置いた瞬間にその人のハンドルが残る、ロックではなく署名。
  • 全ケースの人間確認を強制する仕組み全部を人が確認する道具は使われなくなる。人が見るのは 3 つだけ。
  • Appium / Maestro / scrcpy / Playwright の再実装既にあるものは使う。無いものだけ作る。
  • クラウドの端末ファーム・SaaS 化手元で完結する。相手の画面も証跡も外へ送らない。
  • CI/CD の置き換え・独自 AI モデルの開発git-qa は人が見る場面の道具。自動テストの代わりではない。
git-qa

人が判定する QA ランナー。合格は、人が見て押したときにだけ付く。MIT ライセンス。
