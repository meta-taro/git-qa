git-qa をダウンロード

お使いの PC に合うものを選んでください。見ている PC が分かれば「この PC」と印を付けています。版と落とす先は GitHub のリリースから読んでいます。

最新の版を GitHub から読んでいます…

macOS

Apple シリコン・Intel の両方で動く 1 本（.dmg）。署名と公証をしてあるので、そのまま開けます。端末・ウェブ・デスクトップアプリ・iPhone を見られます。

リリースのページから選ぶ

Windows

x64（Intel・AMD の CPU。ふつうの Windows はこちら）。ウェブ・Android 端末・デスクトップアプリを見られます。

リリースのページから選ぶ

ARM64（Snapdragon などの CPU）。入れ方とできることは x64 と同じです。

入れる前に

Node.js 22 以上が要ります。 アプリの中から実行器を動かすので、入っていないと画面に理由を出して止まります。Node.js の公式サイトから LTS 版を入れてください。

相手によって要るもの

adb（Android SDK Platform Tools） Android 端末を見るときだけ
Chrome / Edge / Firefox / Safari ウェブを見るときだけ。入っているものを選べます（証跡に版が残ります）
ffmpeg / cwebp 任意。無くても止まりませんが、証跡の絵と動画が変換されずに撮れた形のまま残ります。録画には ffmpeg が要ります
WebDriverAgent（iPhone / iPad で押すとき） 見る・読む・録るだけなら不要。押す・打つには端末に入れる必要があり、署名は人の作業です

Windows で、どちらの CPU か分からないとき

設定 › システム ›「バージョン情報」の「システムの種類」が「x64 ベース」なら x64、「ARM ベース」なら ARM64 です。macOS は 1 本で両方に入るので、選ぶ必要がありません。

初めて開くときの確認

Windows のインストーラーは署名していません（証明書に物理トークンか HSM が要るため）。「Windows によって PC が保護されました」と出ます。出どころを確かめてから［詳細情報］›［実行］を押してください。心当たりが無いときは入れないでください。

macOS は署名と公証をしていますので、そのまま開けます。デスクトップアプリを見るときは、初回に画面収録とアクセシビリティの許可を macOS が聞きます。

中身は GitHub のソースから GitHub Actions で作っています。気になるときは、クローンして pnpm install と pnpm app で手元から動かすこともできます。
