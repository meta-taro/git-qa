git-qa / 事例

AI エージェントが作った機能を、実機で確かめさせる

コードを書いたエージェントに、動いた画面まで見せたい。MCP で、Claude Code などのエージェントが画面を撮る・文字を読む・押せる名前を並べる・押すを、Android・ウェブ・デスクトップ・iPhone でできます。 夜のうちに無人で流しておき、朝は落ちた所だけ人が見る。合格を出すのは、それでも人です。

エージェントができること
操作と取得。撮る・読む・押す・なぞる・打つ・アプリを起こす
エージェントができないこと
判定を置くこと。VERIFIED を置く道具は MCP にありません
相手
Android（既定）・ウェブ・デスクトップアプリ。既に起きているブラウザにも繋げる

1. 相手を選んで、MCP を起こす

git-qa のクローンから pnpm mcp で起きます（Claude Code なら .mcp.json に登録済み）。相手は環境変数で選びます。 

$ pnpm mcp                                                        # Android（既定）
$ GIT_QA_MCP_TARGET=web GIT_QA_MCP_URL=http://localhost:3000/ pnpm mcp   # ウェブ
$ GIT_QA_MCP_TARGET=desktop GIT_QA_MCP_APP=メモ pnpm mcp                 # デスクトップ

2. 押す前に、押せる名前を並べる

element_list が、いま画面にある押せる名前を返します。ここに出た文字をそのまま element_tap に渡せば、座標を当てにいかなくて済みます。名前を推し量ると、外れたときにしか気づけません。

element_list 押せる名前を並べる
element_tap 名前で押す（「保存」など）
device_screen_text 画面の文字を読む（相手ごとの読み方で）
device_screenshot いまの画面を絵で取る。場所を渡すとそこにも書く（もう在るファイルには書かない）
device_tap / device_swipe / device_key / device_type / device_launch 1 点を押す・なぞる・HOME などを送る・文字を打つ・アプリを起こす

3. 夜に流して、朝に見る

画面なしで流す（--no-ui）と、人が居なくてもシートを最後まで走らせ、証跡を残します。朝、人は落ちた所と AI が判断できなかった所だけを見て、D か F を置きます。夜のうちの結果は全部 AUTO_PASS のまま。人が押すまで合格にはなりません。

4. 外の道具から、そのケースだけを起こす

検証の漏れを並べる側の道具から、シートとケースを指して git-qa を起こせます（git-qa://run?sheet=…&case=…&target=…）。相手とハンドルが揃っていれば押さずに始まり、走り切ると証跡に終わりの時刻が付きます。
