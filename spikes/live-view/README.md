# live-view スパイク

ライブ映像をウィンドウの中に遅延なく出せるかを測るための使い捨てコード（Issue 003 / ADR 0002）。

**製品のコードではない。**`packages/` からは参照しない。

## 動かす

ffmpeg が要る（`ffmpeg -version` で確認）。

```bash
node spikes/live-view/server.mjs
# → http://127.0.0.1:8787/ をブラウザで開く
```

`testsrc2` の映像が出て、右に fps・復号の待ち・最初の絵までの時間が並ぶ。

## 何を代わりにしているか

scrcpy が吐くのは「生 H.264（Annex-B）の 1 本のストリーム」で、ここでは同じ形を ffmpeg で作っている。
**確かめているのは端末との接続ではなく、その映像を GUI の中に出せるかだけ。**

測った結果と、この代役では確かめられないことは ADR 0002 に書いてある。
