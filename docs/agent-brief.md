# git-qa — AI エージェントへの説明

**これは AI エージェントが読むための文書です。**人向けの案内は `README.md` と
`docs/alpha-guide.md` にあります。**MCP の `about` はこの文書をそのまま返します。**

---

## この道具は何か

**人と AI が一緒に動作検証をするための道具。**

検証シート（TSV）を読み、書かれた手順どおりに画面を操作し、画面の文字を読んで
**下書きの判定**を出す。**合否は決めない。**

---

## あなた（AI）がやってよいこと・やってはいけないこと

| | |
|---|---|
| **やってよい** | 端末・ブラウザ・デスクトップアプリを操作する。画面の文字を取る。下書きの判定を出す |
| **やってはいけない** | **合格（`VERIFIED`）を置くこと。**人が実物を見て 1 打鍵で置いたときだけ残る |

**MCP に判定を置く道具は載せていない。**載せた瞬間、AI が「人が見た」と書けてしまい、
この製品の芯が壊れる。**回り道を探さないこと。**

証跡（`run.json`）には 2 種類が並ぶ。**これを混ぜない。**

- `VERIFIED` / `FAIL` — **人が見て置いた**
- `AUTO_PASS` — **人は見ていない。**道具の判定のまま送った

---

## 読める検証シート

1 行目が `#! md-business:test-spec-tsv/v1`。タブ区切り。
`手順` と `期待結果` の 2 列が要る。

### 手順に書ける言い方

| 書き方 | すること |
|---|---|
| `アプリを起動する` / `ページを開く` | 見出し `# 対象:` が宣言した先を開く |
| `「保存」をクリックする` / `「保存」をタップする` | その文字の場所を押す |
| `「保存」を押す` / `「保存」を押下する` | 同じ。**鉤括弧が要る**（`Enter を押す` と区別できないため） |
| `「お名前」に「テスト太郎」と入力する` | その欄へ打ち込む |
| `「A」を「B」へドラッグする` | 掴んで運ぶ |

### 期待結果に書ける言い方

| 書き方 | 見ること |
|---|---|
| `「保存しました」と表示される` | 画面の文字にそれが在るか |

**鉤括弧が 1 つだけのときに限る。**2 つ以上あるとどちらを見るか決められず、
0 個なら見る文字列が無い。**曖昧なら人へ渡す。**

### 読めない書き方が来たら

**勝手に解釈しない。**「判断できない（`BLOCKED`）」で止まり、
**何が読めなかったかを画面に出す。**端末には触らない。

---

## 相手ごとの違い

| 相手 | 動かし方 | 前面に出るか | 指が動くか |
|---|---|---|---|
| **ウェブ** | ブラウザの中へ命令（CDP / BiDi / WebDriver） | 出ない | 動かない |
| **Android 実機** | 端末へ命令（`adb shell input`） | 関係ない | 動かない |
| **デスクトップ（macOS）** | OS の入力（他に口が無い） | 掴んで運ぶときだけ | なぞる・運ぶで動く |

**デスクトップだけが、アプリの中に喋る道を持っていない。**

## 証跡を後から読み返す

`run.json` には、**判定を置いたときのシートの `sha256`** が入っている。
**それが今のシートと同じかを確かめる口がある。**

```bash
pnpm check:run runs/<日時>/run.json
```

返るのは 4 つのどれか。**混ぜないこと。**

| | 意味 |
|---|---|
| **同じ** | その判定は、いまの文面に対して置かれている |
| **変わっている** | **その判定は、いまの文面に対して置かれたものではない** |
| **シートが読めない** | 消されたか、場所が変わった。確かめられない |
| **記録が読めない** | 証跡の側の値が壊れている。手で書き換えられたかもしれない |

**「同じ」以外は終了コード 1。**気づかずに次へ進まないため。

---

## まだ無いもの（**「ある」と言わないこと**）

- **Windows のデスクトップ検証**（1 行も無い）／**iOS**
- **ウェブの録画**（証跡には「録画していない」と残る。黙って空にしない）
- 押す場所は**画面に見えている文字だけ**。同じ文字が複数あると、
  **いちばん内側の小さいほう**を押す。**行の指定は書けない**
- ログイン済みの状態は引き継がない（**毎回まっさらなブラウザ**）
- 手作業と比べてどれだけ速いか、という数字（**1 度も測っていない**）

---

## 守ること

- **できないことを、できるふりで隠さない。**止まったなら、止まった理由を返す
- **人が何かしたのに、何も言わない**のを作らない。捨てるなら、捨てた理由を返す
- **テストを後回しにしない。落ちるテストを消して通ったことにしない**
- **commit は AI、push は人間**
- **秘密情報は作らない・置かない・貼らない**
- **public リポジトリなので、他の案件の名前を記録に書かない**（踏んだ事実だけ書く）

詳しくは `.claude/rules/product-baseline.md`。
