# git-qa — AI エージェントへの説明

**これは AI エージェントが読むための文書です。**人向けの案内は `README.md`（英語）・`README.ja.md`（日本語）と
`docs/alpha-guide.md` にあります。**MCP の `about` はこの文書をそのまま返します。**

---

## この道具は何か

**人と AI が一緒に動作検証をするための道具。**

検証シート（TSV）を読み、書かれた手順どおりに画面を操作し、画面の文字を読んで
**下書きの判定**を出す。**合否は決めない。**

---

## あなた（AI）がやってよいこと・やってはいけないこと

| | |
|---|---|
| **やってよい** | 端末・ブラウザ・デスクトップアプリを操作する。画面の文字を取る。下書きの判定を出す |
| **やってはいけない** | **合格（`VERIFIED`）を置くこと。**人が実物を見て 1 打鍵で置いたときだけ残る |

**MCP に判定を置く道具は載せていない。**載せた瞬間、AI が「人が見た」と書けてしまい、
この製品の芯が壊れる。**回り道を探さないこと。**

## MCP で触れる相手（2026-09-19）

```bash
GIT_QA_MCP_TARGET=web GIT_QA_MCP_URL=http://localhost:3000/ pnpm mcp   # ウェブ
GIT_QA_MCP_TARGET=desktop GIT_QA_MCP_APP=メモ pnpm mcp                 # デスクトップ
GIT_QA_MCP_TARGET=ios pnpm mcp                                         # iPhone / iPad（押せない）
pnpm mcp                                                               # Android（既定）
```

**押す前に `element_list` を見ること**（2026-09-19 に足した）。

**そこに並んだ文字は、そのまま `element_tap` に渡せる。**これが契約。
**座標を当てにいかないこと** —— 画面を読んで座標を推し量ると、
**別の所を押しても気づけない。****名前を推し量るのも同じ**で、
外れたときにしか気づけない。**並んでいるものから選ぶ。**

`element_list` が空を返したら、**それは「画面に何も無い」ではない** ——
絵からしか読めない相手（Electron など）で起きる。**`device_screenshot` で見て、人に操作を頼む。**

**iPhone / iPad は押せない**（端末側にアプリを入れるのに署名が要る）。
`element_list` は理由を言って断る。**見る・読むだけして、操作は人に頼むこと。**

**既に起きているブラウザにも繋げる**（`GIT_QA_CDP`）。Playwright が前準備を済ませた
ブラウザへ、そのまま続けて触れる。

証跡（`run.json`）には 2 種類が並ぶ。**これを混ぜない。**

- `VERIFIED` / `FAIL` — **人が見て置いた**
- `AUTO_PASS` — **人は見ていない。**道具の判定のまま送った

## 読める検証シート

1 行目が `#! md-business:test-spec-tsv/v1`。タブ区切り。
`手順` と `期待結果` の 2 列が要る。

### 手順に書ける言い方

| 書き方 | すること |
|---|---|
| `アプリを起動する` / `ページを開く` | 見出し `# 対象:` が宣言した先を開く |
| `「保存」をクリックする` / `「保存」をタップする` | その文字の場所を押す |
| `「保存」を押す` / `「保存」を押下する` | 同じ。**鉤括弧が要る**（`Enter を押す` と区別できないため） |
| `「お名前」に「テスト太郎」と入力する` | その欄へ打ち込む |
| `「A」を「B」へドラッグする` | 掴んで運ぶ |

### 期待結果に書ける言い方

| 書き方 | 見ること |
|---|---|
| `「保存しました」と表示される` | 画面の文字にそれが在るか |

**鉤括弧が 1 つだけのときに限る。**2 つ以上あるとどちらを見るか決められず、
0 個なら見る文字列が無い。**曖昧なら人へ渡す。**

### 待つ長さ

**既定は 2 秒。**押すとサーバを 1 往復する行（ログイン → リダイレクトなど）では足りない
（外部レビュー meta-taro/git-qa#39）。**シートの見出しで延ばす。**

```
# 待つ: 8s
```

**`FAIL` が出たとき、まずここを疑うこと。**画面の絵に**押下済み・遷移前**が写っていたら、
**製品の不具合ではなく、待ち切る前に見切っている。**

### 読めない書き方が来たら

**勝手に解釈しない。**「判断できない（`BLOCKED`）」で止まり、
**何が読めなかったかを画面に出す。**端末には触らない。

## 相手ごとの違い

| 相手 | 動かし方 | 前面に出るか | 指が動くか |
|---|---|---|---|
| **ウェブ** | ブラウザの中へ命令（CDP / BiDi / WebDriver） | 出ない | 動かない |
| **Android 実機** | 端末へ命令（`adb shell input`） | 関係ない | 動かない |
| **デスクトップ（macOS）** | OS の入力（他に口が無い） | 掴んで運ぶときだけ | なぞる・運ぶで動く |
| **iPhone / iPad** | **動かせない**（押す口が無い） | 出ない | 動かない |

**デスクトップだけが、アプリの中に喋る道を持っていない。**
**iPhone / iPad だけが、そもそも動かせない** —— 見て読むだけ。**操作は人に頼むこと。**

## 証跡に残るもの

```
runs/<日時>/
  run.json              判定・手順・時刻
  case-001/screen.webp  **判定を置く時点の画面**（ケースごと）
  case-001/screen.webm  録画（**頼まれたときだけ**・`--record`）
```

**画面は、人へ渡す前に撮る。**人が考えている間に画面が動くと、
「人が見たもの」と「残った絵」がずれるため。

**形は webp。**ウェブはブラウザがそのまま出す。デスクトップと Android は
`cwebp` か `ffmpeg` が**在れば**変換し、**無ければ撮れた形のまま置く**
（`screen.jpg` / `screen.png`）。**名前と中身は必ず一致する。**

**無いときは理由が残る。**`screenshot.state` が
`saved` / `not_requested` / `failed` / `unsupported` のどれかになる。**黙って空にしない。**

## 証跡を後から読み返す

`run.json` には、**判定を置いたときのシートの `sha256`** が入っている。
**それが今のシートと同じかを確かめる口がある。**

```bash
pnpm check:run runs/<日時>/run.json
```

返るのは 4 つのどれか。**混ぜないこと。**

| | 意味 |
|---|---|
| **同じ** | その判定は、いまの文面に対して置かれている |
| **変わっている** | **その判定は、いまの文面に対して置かれたものではない** |
| **シートが読めない** | 消されたか、場所が変わった。確かめられない |
| **記録が読めない** | 証跡の側の値が壊れている。手で書き換えられたかもしれない |

**「同じ」以外は終了コード 1。**気づかずに次へ進まないため。

## まだ無いもの（**「ある」と言わないこと**）

- **iPhone / iPad を押すこと。**見る・読む・録るは叩きが入っている（2026-09-19）。
  **押すには端末側にアプリ（WebDriverAgent）が要り、署名が要る＝人の作業。**
  **「iOS は 1 行も無い」と書かないこと** —— ここにそう書いてあったせいで、
  **動く Windows のデスクトップ検証まで検討から外させていた**（外部レビュー meta-taro/git-qa#23）
- **iPhone / iPad は実機で 1 度も測っていない**（2026-09-19 時点）。
  **「動く」と言わないこと。**建つことと、端末が無いときの振る舞いだけ確かめてある
- **Windows のデスクトップ検証は「ある」。**ただし**録画が無い**（画面は 1 件ごとに残る）。
  **「穴がある」と「無い」を混ぜない**
- 押す場所は**画面に見えている文字だけ**。同じ文字が複数あると、
  **いちばん内側の小さいほう**を押す。**行の指定は書けない**
- 手作業と比べてどれだけ速いか、という数字（**1 度も測っていない**）

## 守ること

- **できないことを、できるふりで隠さない。**止まったなら、止まった理由を返す
- **人が何かしたのに、何も言わない**のを作らない。捨てるなら、捨てた理由を返す
- **テストを後回しにしない。落ちるテストを消して通ったことにしない**
- **commit は AI、push は人間**
- **秘密情報は作らない・置かない・貼らない**
- **public リポジトリなので、他の案件の名前を記録に書かない**（踏んだ事実だけ書く）

詳しくは `.claude/rules/product-baseline.md`。
