# git-qa アルファ版 — 使ってみる人への案内

**この版は、実際の検証で試しに使ってもらうために出しています。**動かなかったら、
そのまま指摘してください。**直すのはこちらの仕事です。**

---

## この道具が引き受けること／引き受けないこと

| | |
|---|---|
| **引き受ける** | 検証シート（TSV）を読み、手順どおりに操作し、画面を読んで**AI が下書きの判定を出す**。証跡（`run.json`）を残す |
| **引き受けない** | **合否を決めること。**`VERIFIED`（合格）は、**人が実物を見て 1 打鍵で置いたときだけ**残ります |

証跡には 2 種類の結果が並びます。**これを混ぜません。**

- `VERIFIED` / `FAIL` — **人が見て置いた**
- `AUTO_PASS` — **人は見ていない。**AI の判定のまま送った

---

## 使えるもの（アルファ版の範囲）

| 相手 | 状態 |
|---|---|
| **ウェブページ**（ローカル / 公開 URL） | 動きます。**今回の本命** |
| **デスクトップアプリ**（macOS） | 動きます。**画面収録とアクセシビリティの許可が要ります**（初回に macOS が聞きます） |
| **Android 実機・エミュレータ** | 動きます（USB 接続 + `adb` が要ります） |
| iOS / Windows | **ありません** |

## 配る側へ — 別の Mac に入れるとき

**渡すもの**: `git-qa_0.0.0_aarch64.dmg`（3.0 MB）

**受け取る側に必要なもの**（**足りないと起動しません**）

| | 要る理由 | 無いとどうなるか |
|---|---|---|
| **Apple Silicon の Mac** | dmg が `aarch64` 版 | Intel Mac では動きません |
| **Node** | アプリの中身が Node で動いている | `Node を起こせない（node が要る）` で止まります |
| **Chrome** | ウェブページを見るのに使う | ウェブ検証ができません |
| adb | Android を見るときだけ | Android 検証ができません |

> **Node が要るのは、いまのアルファ版の作りの都合です。**同梱する形にはまだしていません。
> 入っていない相手に配るなら、先に Node を入れてもらってください。

### 入れる手順

1. dmg を開き、`git-qa.app` を**アプリケーションフォルダへドラッグ**
2. **そのままでは開けません。**署名がまだなので、macOS が止めます

   **他の Mac へコピーした場合は「壊れているため開けません」と出ます。**
   壊れてはいません。macOS が「どこから来たか分からない」印を付けているだけです。
   ターミナルで 1 回だけ、この行を実行して印を外します。

   ```bash
   xattr -dr com.apple.quarantine /Applications/git-qa.app
   ```

3. もう一度開く。まだ止められる場合は
   **システム設定 → プライバシーとセキュリティ**の下のほうに出る**「このまま開く」**

> **署名すれば、この手順は要らなくなります。**配る人数が増えるなら、先に署名したほうが楽です。

## はじめかた（ウェブページ）

### 1. アプリを開く

`git-qa.app` を開きます（初回だけ、上の「入れる手順」が要ります）。

### 2. 3 つ埋める

| 欄 | 入れるもの |
|---|---|
| **0. あなたのハンドル** | 証跡に「誰が見たか」として残る名前。日本語で構いません |
| **1. 見る相手** | **ウェブなら URL の欄**（`http://localhost:3000/` など）。**デスクトップアプリならアプリ名の欄**（窓の題ではなく、**窓の持ち主の名前**）。**Android なら一覧から選ぶ** |
| **2. 検証シート** | 一覧から選ぶ。無ければ「別の場所から選ぶ…」 |
| **見るブラウザ** | 下記から選ぶ。**選んだものの版が証跡に残ります** |

**選べるブラウザ**

| | 状態 |
|---|---|
| **Chrome** / **Firefox** / **Safari** | ✅ **動かして確かめてあります** |
| Edge / Brave / Opera / Vivaldi / Chromium | ⏳ 同じ仕組みで動くはずですが、**まだ確かめていません** |
| **その他（場所を指定する）** | セキュリティソフト付属のブラウザなど。**中身が Chromium なら動きます** |

> **Safari を使うときだけ、1 回設定が要ります。**
> Safari の設定 →「デベロッパ」タブ →「リモートオートメーションを許可」。
> （「デベロッパ」タブが無ければ、先に「詳細」タブの「Web デベロッパ用の機能を表示」）
>
> 入っていなければ、**画面にその手順が出ます。**

> **証跡には、実際に起きたブラウザの版が入ります**（例: `Google Chrome（Chrome/152.0.7977.77）`）。
> 同じ画面でも版が違えば結果が変わるので、後から読み返すときの手がかりになります。
>
> **毎回まっさらなプロファイルで開きます。**普段の Chrome の履歴・ログイン・拡張は
> 引き継ぎません（人の Chrome を汚さないため）。**ログインが要る画面は、
> シートの 1 件目からログイン手順を書いてください。**

**「検証を開始する」が緑になったら押せます。**押せないときは、ボタンのすぐ下に**理由が出ます。**

### 3. 見て、置く

真ん中にページが出ます。AI が手順を実行し、1 件ごとに止まって**あなたの打鍵を待ちます。**

| キー | 置くもの |
|---|---|
| `d` | **合格**（自分の目で見て確かめた） |
| `f` | **不合格**（自分の目で見て確かめた） |
| `a` | **判断できない**（人が見ても決められない） |
| `s` | このケースは今回見ない |
| `Space` | **置かずに次へ** —— AI の判定のまま（`AUTO_PASS`）残ります |
| `↑` `↓` | 前後のケースを見る（**見るだけ。判定は動きません**） |

終わると `runs/<日時>/run.json` が出ます。**置いた判定はここに残ります。**

## 検証シートの書き方

先頭に見出し、そのあとに表を書いた TSV です。**見本は `sheets/web-sample-ja.tsv`。**

```
#! md-business:test-spec-tsv/v1
# タイトル: 注文フォーム 検証シート
# 対象: http://localhost:3000/
No.	項目	手順	期待結果
1	ページが開く	ページを開く	「注文フォーム」と表示される
2	送信できる	「送信」をクリックする	「送信しました」と表示される
```

**`# 対象:` に書いた URL だけを開きます。**手順の中で別の場所へは行きません。

### いま読める手順

| 書き方 | すること |
|---|---|
| `ページを開く` / `ページを起動する` | `# 対象:` の URL を開く |
| `https://… を開く` | そこを開く |
| `「保存」をクリックする` | その文字の場所を押す（タップと書いても同じ） |
| `「保存」を押す` | 同じ（押下する も同じ）。**鉤括弧が要る** —— `Enter を押す` のようなキー操作と区別できないため |
| `「お名前」に「テスト太郎」と入力する` | その欄へ打ち込む（**ウェブなら日本語も入ります**） |

### いま読める期待結果

| 書き方 | 見ること |
|---|---|
| `「保存しました」と表示される` | 画面の文字にそれが在るか |

**読めない書き方は、勝手に解釈しません。**「判断できない（`BLOCKED`）」として止まり、
**何が読めなかったかを画面に出します。**その文をそのまま教えてください。

## まだ無いもの（正直に）

- **iOS**
- **ウェブの録画**（証跡には「録画していない」と残ります。黙って空にはしません）
- **押す場所の指定は、画面に見えている文字だけ。**同じ文字が複数あると、
  **いちばん内側の小さいほう**を押します
- 手作業と比べてどれだけ速いか、という数字（**1 度も測っていません**）
